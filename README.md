# Mohamed — Developer Portfolio

A responsive personal portfolio built with HTML5, CSS3, Bootstrap 5, and Bootstrap Icons.

## Features
- Dark navy and blue visual design
- Responsive navigation and layouts
- About, skills, projects, and contact sections
- Custom CSS project previews (no image assets required)
- Bootstrap mobile navigation
- Small JavaScript enhancement for the current year and mobile menu

## Run locally
Open `index.html` in a browser. An internet connection is needed to load Bootstrap, Bootstrap Icons, and Google Fonts from their CDNs.

## Before publishing
1. Replace the sample email `your.email@example.com` with your real public contact email.
2. Replace the GitHub and LinkedIn profile links with your own URLs.
3. Update skill indicators to reflect your actual level.
4. Replace practice project cards and generic GitHub links with your real repositories when available.
5. Do not claim that planned practice projects are completed projects.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub (for example, `mohamed-portfolio`).
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish. Your site URL will appear in the Pages section, usually `https://YOUR-USERNAME.github.io/mohamed-portfolio/`.

The repository URL and the live website URL are different. Submit the repository URL if the assignment specifically asks for the GitHub repository link.
